# tank-level-control-arduino
Automatic tank filling and draining system using Arduino
## 📌 Description
This project presents an automated system for filling and draining a water tank using Arduino.

## ⚙️ Components
- Arduino UNO
- Water pump
- Solenoid valve
- Level sensors (Low / High)
- LEDs (status indicators)
- Switch & push button

## 🔁 System Operation
- The system automatically fills the tank when water is low
- Stops filling when tank is full
- Prevents overflow and dry running

## 💡 Technologies
- Arduino (C/C++)
- Proteus (simulation)
